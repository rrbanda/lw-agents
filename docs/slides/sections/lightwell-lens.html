Lightwell Lens

Quantify Coverage Instantly

Lightwell Lens gives you a fast, actionable way to assess Lightwell’s value against your actual software inventory. Upload an SBOM or manifest and see exactly what the Lightwell Network already covers today.

How It Works

Upload SBOM SPDX, CycloneDX, pom.xml, requirements.txt
→
Lens Analysis Match against Lightwell catalog
→
Coverage Report Exact & partial matches, ecosystem breakdown

Supported Formats

SPDX CycloneDX pom.xml requirements.txt Package URLs (PURL)

What You Get

✅ Exact Matches

Packages with both exact name and version in the Lightwell Network catalog. These are ready to consume today.

🔄 Partial Matches

Package name exists in the catalog but the pinned version is not yet present — easy pathing to full coverage.

📊 Ecosystem Breakdown

Visual coverage statistics organized by language and ecosystem — Java, Python, and growing.

📚 Itemized Inventory

Searchable breakdown of every matched and unmatched package for detailed planning and prioritization.

Positioning note: Even small coverage fractions deliver massive security value for critical dependencies. Quality and impact far outweigh raw volume. The catalog is expanding rapidly with 15,000+ package versions and accelerating daily.

For continuous day-2 monitoring and long-term adoption tracking, pair Lightwell Lens with Red Hat Trusted Profile Analyzer (TPA) — providing ongoing SBOM lifecycle management and vulnerability correlation across your software supply chain.
