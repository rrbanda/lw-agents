What Makes This Possible

⚙ Google ADK 2.0

Agent harness providing the core loop, tool dispatch, state management, skills, and plugins. The orchestration backbone for every agent in the pipeline.

👥 5 Specialist Agents

Coordinator delegates to selection, analysis, remediation, test-gen, and validation agents — each with domain-specific skills and tools.

📖 Skills-as-Playbooks

7 SKILL.md files encode expert methodology. Agents load the playbook before acting, not after — ensuring consistent, auditable behavior.

Enterprise Trust at Machine Speed

🚧 Policy Gates

Pre-gate validates inputs before spending tokens. Post-gate rejects forbidden patterns in diffs. No unsafe code leaves the pipeline.

🛡 Safety Plugins

LLM-as-judge safety screening plus secret redaction on every tool response. Defense in depth at the model layer.

✅ Fail-Closed Scoring

Deterministic validation — no LLM involved in the final pass/fail decision. If the tests don’t pass, the patch doesn’t ship.

📈 Two-Layer Eval

Model safety (EvalHub) plus 38 agent behavior cases run on every code push. Continuous regression testing across the full stack.
