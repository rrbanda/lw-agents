Agent Hierarchy

Coordinator and Five Specialists

The root agent is a delegator — it never attempts tasks itself. Based on the request type, it routes to the appropriate specialist.

Root Coordinator

ssc_coordinator (LlmAgent)

Role: Delegates by task type. Never attempts work itself.

SafetyPlugin RedactionPlugin

Callbacks: init_structured_result (before), extract_structured_results (after)

Sub-agents: cve_selection, cve_analysis, remediation, test_generation, fix_validation

Five Specialists

CVE Selection (LlmAgent)

Selects the single best CVE to remediate from a policy-gated must-fix set by exploring each CVE incrementally via tools.

cve-triage scm-conventions

Tools:

  • list_must_fix_cves
  • lookup_cve_detail
  • parse_maven_purl
  • check_version_exists

Callback: fail_closed_selection_callback (after)

Output: selection_result

CVE Analysis (LlmAgent)

Analyzes every CVE in the must-fix set, evaluates fixability via tools, and returns a JSON decisions array.

  • check_version_exists

The coordinator pattern ensures clear separation of concerns. Each specialist has exactly the tools and skills it needs — no more. This is the principle of least privilege applied to agent capabilities.
