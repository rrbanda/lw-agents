Multi-Persona Validation

Adversarial Review with Deterministic Scoring

Fix validation uses a multi-persona pattern: two LLM personas (security architect + penetration tester) provide independent assessments, then a deterministic scorer (no LLM) calculates the final verdict. All personas are read-only — no write tools, no bash.

Deterministic Consensus

🧮 DeterministicScoring — BaseAgent, NO LLM

The DeterministicScoring agent uses no LLM. Pure weighted math.

Conservative consensus:

  • Both personas agree → HIGH confidence
  • Disagreement → most-conservative-wins with FLAGGED confidence

Severity ranking: fail < partial < inconclusive < pass. On disagreement, the minimum (most severe) status is chosen.

Critical gate cap: If root_cause is not PASS, the decision is capped down one level (FIXED → PARTIALLY_FIXED).

Why deterministic scoring? The final pass/fail decision is deliberately not an LLM. Pure math — no hallucination, no prompt sensitivity, no model drift. The LLMs provide the analysis; the math provides the verdict. A bad fix is more costly than a delayed fix, so the system is designed to fail conservative.
