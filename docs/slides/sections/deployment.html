Deployment

From Code to OpenShift

The agent service runs as a Deployment on OpenShift, fronted by a Service and Route, with configuration via ConfigMap and Secrets. Tekton pipelines handle the full CI/CD lifecycle including eval gates.

Container Image

UBI9 Python 3.12

Single all-in-one image containing everything the agent needs at runtime:

JDK 17 + Maven 3.9.9 glab CLI v1.48.0 gh CLI v2.63.2 OpenCode ADK Agent Service

Entry point: python -m google.adk.cli web --host 0.0.0.0 --port 8080 /sandbox
Build: podman build --platform linux/amd64 -t <image> -f Dockerfile .

Tekton Integration

call-ssc-agent

Thin HTTP caller that POSTs task type + workspace to the agent service via curl. Maps agent responses to Tekton results. Supports select-cve, analyze-cves, remediate, and generate-tests task types.

evalhub-eval-gate

Submits EvalHub benchmarks via eval-hub-sdk, waits up to 1800s for completion, and fails the pipeline if safety or quality thresholds are not met.

agent-eval-gate

Runs 38 agent test cases via app.eval.agent_eval with regression detection against baseline.json. Logs all results to MLflow.

scheduled-agent-eval

CronJob (0 */6 * * *) triggers the full eval pipeline every 6 hours. Catches model drift and infrastructure changes between code pushes.

Namespace Layout

tssc-app-ci

Tekton PipelineRuns, task pods (clone, build, scan, eval-gate, call-agent), EventListener, CronJob. The existing CI/CD namespace.

tssc-agents

Agent Deployment (lw-agents, replicas: 1), Service (lw-agents, port 8080), Route (TLS edge). The agent runs here with ConfigMap and Secrets.

redhat-ods-applications

EvalHub service (TrustyAI operator), MLflow service (experiment tracking + OTLP traces). Managed by RHOAI 3.5.

Key Makefile Targets

Target What It Does
make dev Local development — uv run adk api_server app
make test Unit tests — uv run pytest tests/ -xvs
make agent-eval Run 38 eval cases against live service (6 agents)
make build Container image build via podman/docker (linux/amd64)
make push Push agent + sandbox images to registry
make deploy Kustomize apply to cluster + rollout status wait
make ci-gate Full CI quality gate: model safety + model security + agent evals
Local development is one command: make dev. The same agent code runs locally and in production. The only difference is configuration — model endpoints, SCM tokens, and MLflow URI come from environment variables.
